# How to edit the website · Como editar o site · Cómo editar el sitio

## English
1. Go to **https://app.pagescms.org** and sign in (with GitHub, or with the email invitation you received).
2. Open the **everybookitsreader** project.
3. Choose **Pages (English)** or **Páginas (Português)**, click a page, and edit it like a normal document.
4. Click **Save**. The live site updates in about a minute.

Menu and footer text are under **Site settings**. To add an image, use the image button in the editor or the **Media** section.
If something goes wrong, every change is kept in history and can be undone — just ask Laurie.

## Português
1. Acesse **https://app.pagescms.org** e entre (com o GitHub ou pelo convite enviado por e-mail).
2. Abra o projeto **everybookitsreader**.
3. Escolha **Páginas (Português)** ou **Pages (English)**, clique numa página e edite como um documento comum.
4. Clique em **Save**. O site é atualizado em cerca de um minuto.

O texto do menu e do rodapé fica em **Site settings / Configurações**. Para adicionar imagens, use o botão de imagem no editor ou a seção **Media**.

## Español
1. Entra en **https://app.pagescms.org** e inicia sesión (con GitHub o con la invitación que recibiste por correo).
2. Abre el proyecto **everybookitsreader**.
3. Elige **Pages (English)** o **Páginas (Português)**, haz clic en una página y edítala como un documento normal.
4. Haz clic en **Save**. El sitio se actualiza en aproximadamente un minuto.

El menú y el pie de página están en **Site settings**. Para añadir imágenes, usa el botón de imagen del editor o la sección **Media**.
